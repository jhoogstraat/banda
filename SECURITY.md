# Security

Banda runs untrusted code (the repository, the agent) in sandboxes that hold a user's Claude login and secrets. The known risks and what Banda does about them are listed under "Constraint: Claude subscriptions" in [PLAN.md](PLAN.md) (open risks 5–9); read them before running Banda for anyone but a team that trusts each other.

Please report vulnerabilities privately through GitHub's "Report a vulnerability" on the repository's Security tab, not in a public issue.
